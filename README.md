## อัปขึ้น GitHub Pages
1. สร้าง repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. Source: **Deploy from a branch**
5. Branch: **main** / **root**
6. Save
7. รอ GitHub สร้าง public URL
